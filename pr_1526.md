## Description

This PR implements the requested LinkedIn integration for the Portfolio Builder (Issue #1526). It enables users to sync their professional data directly from LinkedIn into their NexaSphere portfolio.

### Features
- **LinkedIn OAuth Flow**: Implemented `/api/portfolio/linkedin/auth` and `/callback` to securely request authorization and fetch user data via the LinkedIn API.
- **Skills Extraction**: Automatically imports the user's top skills into the Portfolio builder.
- **Job History Import**: Extracts Work Experience details, including company names, roles, and start/end dates.
- **Fallback Mock Support**: If LinkedIn credentials (`LINKEDIN_CLIENT_ID` / `LINKEDIN_CLIENT_SECRET`) are not present in `.env`, the flow seamlessly falls back to returning mock data for development and testing.

### Changes
- Added `linkedinHelper.js` for OAuth flow handling and API logic.
- Updated `portfolio.js` router to expose the two new endpoints.
- Updated `PortfolioBuilder.jsx` UI to add a "Connect LinkedIn" button, capture the OAuth callback payload via the `message` event listener, and display imported work experiences alongside existing GitHub synced projects.
